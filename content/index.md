# Lin-lee's blog

这里记录我对 Java 后端、JVM、并发模型、可观测性和工程实践的学习与思考。

文章会尽量从真实问题出发：先讲清楚背景，再展开实现机制、生产边界和取舍。

## 主要方向

- Java / JVM：语言特性、运行时机制、虚拟线程、GC、性能分析。
- 后端工程：Servlet、Spring、数据库、消息队列、服务治理和系统可靠性。
- 可观测性：日志、指标、链路追踪、profiling，以及它们在生产排障里的实际作用。
- AI 工程化：Agent、工具调用、评测、回放和面向真实业务的落地边界。
